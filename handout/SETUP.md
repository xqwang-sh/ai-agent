# 第一讲准备清单

先读[零基础必看入门](../start-here/index.html)，按需完成工具、工作目录、运行环境和模型授权的准备。做过的不用重做。

- [ ] 编程 Agent 已连接编码模型，能在本机项目中读写文件、执行程序。
- [ ] Node.js 与 npm 的最小运行检查已通过。
- [ ] 已解压[第一讲实操材料](../lesson-one-materials.zip)，用 Agent 打开 `earnings-workflow`，能看到 `TASKBOOK.md`、`AGENTS.md`、`data`、`contracts`、`prompts`、`history` 和 `checks`。
- [ ] 已准备本人的硅基流动 Key，知道它与编码模型授权分开。

暂时没有财报运行 Key，可以先完成离线搭建，第 7 步真实 Run 前补齐。Key 只填在自己网页 Evals 的隐藏输入框，不发到聊天中。本讲从完整的 207 页报告文本开始，不需要自己获取 PDF 或连接同花顺。

确认后，回到[第一讲讲义](../handout.html#purpose)继续阅读。按第 0–7 步，在同一项目会话中逐条发送主 Prompt，等本步完成并核对结果后再继续。本讲用 OpenCode 示范，已有可用编程 Agent 的老师可以继续用自己的工具。

材料包没有成品程序。第 0 步核对项目与运行条件，第 1 步建立网页并说明启动、停止和重开方法。后续操作跟随对应步骤；历史收据和离线测试不能代替本人的真实 Run。
