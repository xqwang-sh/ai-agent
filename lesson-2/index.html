从本地 PDF 到可核验的复盘网页

用自己的 Agent，搭建 Earnings Review

从本地半年报文件夹开始，做出能运行、能核验、能追溯的财报复盘网页。

本讲假设你已经安装 OpenCode。接下来每次复制一条 Prompt，让自己的编程 Agent 写出一部分程序、运行检查，再由你核对结果。完成后，用户只需要选公司、选模型、点运行，就能看到进度、两层核验和公司的半年报 Earnings Review。

材料包只有六份完整 2026 半年报、任务书、数据约定、合成检查案例，以及四份通用运行时提示词。没有成品程序、预填的财务结果、预选页码或 API Key。

动手之前，先看程序和模型怎样配合

从完整 PDF 到 Earnings Review，程序负责读文件、执行工具、计算和检查；模型负责寻找证据与抄录。先沿着下面的箭头看一遍，再开始第 0 步搭建。

检查不通过，走这条补证分支

  1. 程序保存失败阶段、失败原因与已有进度。
  2. 将这些信息交回同一会话；不提供正确答案、差额或正确页码。
  3. 模型自行检索、读页或重提完整候选，程序仍按相同规则检查。
  4. 文字候选改变后，重新计算，并重新启动独立视觉核验和外部核验。

视觉自身引用失败留在该视觉会话内续跑。所有调用共享总预算；达到请求、tokens、时间准入阈值，或连续无进展、重复失败，就停止并保存原因。服务或用量异常也会停止，不生成本轮复盘。

↖ 回到检索、读页与补证

图中的定位、文字抄录与独立视觉是不同的模型任务。初次定位和初次抄录各发起请求；工具往返、补证和视觉续跑会增加调用次数，全部计入本轮 tokens 与耗时。

每一步具体做什么

步骤谁执行输入、操作与输出
1．PDF 转逐页文字程序每份报告提取一次，保留每个物理页的完整文字和源文件指纹，空白页也计数；后续读取同一份快照。
2．生成导航索引程序为每页生成包含页头、单位或指标附近文字的导航卡。覆盖所有物理页号，文字有省略，不能直接作为完整财务证据。
3．定位证据页文本模型读取全部导航，判断哪些页包含合并利润表、续表、金额单位和 EPS 单位，返回页码与原文锚点；需要时自行请求检索全文、读取指定页，由程序执行。
4．读取完整页程序检查页码与锚点是否真实存在，读取所选整页，检查关键线索是否缺失。不通过时记录原因并进入受预算约束的补证，不向模型补入正确页码。
5．抄录原值文本模型读取完整证据页，输出五项指标的两期数字、原单位、年份列头、合并口径与出处。保留括号、负号和引文，不计算。
6．检查来源程序检查字段、引用页、单位原句，以及数字是否出现在对应指标附近。不通过时保留失败；文字检查通过，也仍需后面的独立核验。
7．换算、计算程序用 Decimal 按原单位换算金额，EPS 保持元/股，用固定公式计算同比；上期不为正时同比不适用。原值与候选计算表分别保存，未核验结果不进入最终复盘。
8．内部视觉核验独立视觉模型＋程序新的视觉会话只看选定原始页图与任务，不看文字答案或同花顺参考值。重新抄录后由程序核对数值、单位和证据，保存内部核验记录。
9．外部数据核验程序＋同花顺取得同一公司、相同累计 H1 口径的两期数据，按 PDF 原单位与披露精度逐项比较。参考数值由程序保管，不进入模型补证反馈。
10．生成网页复盘程序当前版本的两层核验通过后，封存原 PDF、页图、原值、计算与核验记录，生成财务表、同比、利润率、图表与证据链接。每步模型、tokens、耗时和全部续跑留在同一账本。

本讲已经接通内部视觉核验、同花顺比对和网页交付，这三部分与前面的取证、计算使用同一条实线流程。最终交付是 Earnings Review 网页。

网页将这些操作归到六个运行步骤：读取 PDF、定位证据、抄录与补证、内部视觉核验、同花顺外部核验、生成复盘。逐页文字与导航属于“读取 PDF”；完整读页、来源检查和初步计算主要发生在“抄录与补证”。利润率等展示指标由“生成复盘”读取已核验原值确定性计算。

先分清谁在搭建，谁在运行

你正在使用的编程 Agent

例如 OpenCode。它负责读任务、写文件、启动程序、检查和修复。这里的主 Prompt 都发给它。

做出来的财报 Agent

是你本机的一个程序。它按固定阶段运行，用工具读 PDF，调用财报模型，检查证据并更新网页。

程序调用的财报模型

主线使用 Qwen 27B 做文字抄录和独立视觉复读。它与 OpenCode 当前使用的编码模型是两项配置。

固定的是阶段、财务口径、检查规则和停止条件。证据页由模型借助检索和读页工具自行寻找。把程序做出来之后，日常点网页运行不需要 OpenCode 留在对话中。

同一流程在网页中的六个运行步骤

  1. 程序读取 PDF

    检查文件身份，抽取整份逐页文本并生成导航。

  2. 模型＋工具定位证据

    模型选择物理页，必要时检索全文、读取页面。

  3. 模型＋程序抄录与补证

    模型保留原值和单位，程序检查来源并计算。

  4. 视觉模型＋程序内部核验

    新会话盲读页图，程序比较两次独立抄录。

  5. 同花顺＋程序外部核验

    取独立两期数据，按原披露精度逐项核对。

  6. 程序生成复盘

    核验通过后封存证据，计算同比和利润率，更新网页。

做到什么程度算完成
  • 公司列表来自本地真实 PDF；新增一份符合条件的报告，重新扫描就能出现。
  • 点击运行后产生真实任务，六个阶段显示实际状态、模型、tokens 和耗时。
  • 内部核验独立读取原始页图，外部核验与同花顺数据逐项对照。
  • 检查失败时交回失败原因和已有进度；达到预算或无进展条件就停止。
  • 只有当前版本的两层核验都通过，才生成带证据链接的复盘。

打开一个新项目

  1. 准备一个新项目

    新建名为 earnings-review 的空文件夹。下载并解压实操材料包，把包内 earnings-review 文件夹里的内容放进这个项目。确认 reports 下面有六份 PDF，contracts 和 prompts 也在项目根目录。

  2. 让 OpenCode 打开这个文件夹

    使用你已安装的 OpenCode 打开 earnings-review。在输入框中发送下面第 0 步的 Prompt。后续始终在同一个项目里操作。若只给方案不写文件，检查是否处于允许编辑的 Build 模式。

  3. 确认编码模型可以工作

    先让 OpenCode 正常回复一句话并读取当前项目。如果尚未连接模型，在它的连接入口完成配置；终端版常用 /connect 和 /models。具体界面以你安装的版本为准，不要求换装另一版本。

  4. 准备程序运行所需的服务

    财报模型的服务端 API 凭据，以及同花顺金融数据服务凭据，需要单独确认。OpenCode 能聊天，不代表生成的程序能读取同一项授权。第 0 步会检查缺什么，并给出适合你电脑的配置方法。 暂无服务凭据时，可以先搭建离线模块；第8步真实运行前必须补齐，不能把未完成写成通过。

OpenCode 的连接与模型选择见 官方使用文档、模型配置。这些入口可能随版本调整；本讲不依赖某个固定快捷键。
