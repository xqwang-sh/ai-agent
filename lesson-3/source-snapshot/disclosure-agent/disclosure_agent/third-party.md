# Excel reader

SheetJS Community Edition mini 0.20.3 is vendored as `xlsx.mini.min.js` for local `.xlsx` reading. No CDN request is made by the product.

- Source: https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.mini.min.js
- SHA-256: `0cb353f830d7288385492c83d277b058ddeac664ca51cf1393aa1fd3e2b70939`
- License: Apache-2.0, retained in `sheetjs-license.txt`.
- Installation: https://docs.sheetjs.com/docs/getting-started/installation/standalone/
- Parsing: https://docs.sheetjs.com/docs/api/parse-options/

`watchlist-example.xlsx` is an editable template built with the bundled spreadsheet authoring library. Codes are stored as text; the six-digit display format also protects leading zeroes when a user enters a number.
