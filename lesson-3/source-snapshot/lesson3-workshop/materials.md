# 第三讲材料

先用自己的编程Agent在空目录搭建。起步包只有短业务需求和公司身份，原公告由自己的Agent从巨潮查询。

- [起步包](lesson3-starter.zip)：两份小文件，用于第0至1步。
- [本期三季度核验包](lesson3-q3-validation.zip)：18份PDF、40页；按2份起步、8份新模板、8份真实变更留出分批核验。先保留首次模型原答，再使用候选标准评分。
- [扩围后追加检查](lesson3-expansion-checks.zip)：7份PDF、15页，来自扩围后发现的编号、分类和版式问题，只作事后回归，不并入原18份首次成绩。
- [历史回归包](lesson3-validation.zip)：原12份、35页，含范围外类型；隔离测试，不作为当前三季度产品输入。
- [教师参考实现](lesson3-teacher-reference.zip)：完整程序、测试与使用说明，供教师核对或明确说明后的恢复；不作为默认起步项目。

金标准仍为独立读源形成的候选，需任课教师抽查签认。运行时程序不读取标准答案，提取模型第一次请求不能包含teacher-gold、教师参考字段或评分差异。

讲义与冻结日历是可审阅的展示。实时结果由自己的Agent生成；刷新展示网页不会调用模型。

- [关注公司 Excel 模板](watchlist-example.xlsx)：每行填简称或股票代码，导入产品后同时筛选多家公司。本机记住名单；例子中的001301保留六位格式。
