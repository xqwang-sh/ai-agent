# 零基础必看入门

金融智能体系列讲座 · 第一至三讲课前必做 · 更新于 2026 年 10 月 31 日

这份讲义写给平时使用 Word、Excel、PPT，没有编程经验，也没有配置过 API 的老师。拿着你准备带来上课的电脑，一边读，一边操作。完成后，你要能让 AI 读到自己电脑上的文件、把结果保存成文件，并确认课堂需要的服务确实能用。

不需要另领练习包。所有操作、可复制文字和核对方法都在本页。需要的文件由你在自己的电脑上创建，文档读取检查使用你手头已有的非敏感资料。

建议分两次完成，预留约两小时。下载、注册和网络排障可能需要更久，以完成每步检查点为准。

## 先知道怎样才算准备好了

看到 AI 回复“完成了”，还不能继续。每一步都要留下一项你能亲自检查的结果。文件要在电脑上找到，网页要实际打开，服务要收到真实返回。

本页的勾选只保存在当前浏览器，表示你已经自行核对，不是系统自动验收。不要在本页填写 API Key。最后一节会把检查结果整理成一份不含密钥的课前记录。

| 你要完成的事 | 你怎样亲自确认 |
| --- | --- |
| 安装并连接编程工具 | 在工具中收到回复，还能让它读取、创建文件 |
| 找对自己的工作文件夹 | 电脑中的文件和 AI 说出的路径对应得上 |
| 看懂常见文件格式 | 能说明一个 PDF 用了什么读取方法，核对一段文字和一行表格 |
| 接通模型服务 | 自己做出的检查程序收到硅基流动的真实响应 |
| 接通数据服务 | 同花顺返回指定公司的真实财务数据，能看清报告期和单位 |
| 访问第三讲来源 | 能在巨潮查到公告并打开原始 PDF |

已有其他能读写文件、运行程序的编程智能体，可以继续使用，不必为本课再装一套。下文只展开一条共同路线：OpenCode 桌面版连接 DeepSeek。选择其他工具的老师，仍需完成相同的结果检查。

## 第1步：在自己的电脑上建一个工作文件夹

“项目”在本课里首先就是一个文件夹。原始资料、AI 写出的程序、结果和记录都要有明确位置。一次对话不等于已经保存了一份文件。

### 现在怎么做

1. 打开电脑上的“文档”位置。Windows 用文件资源管理器，Mac 用 Finder，也就是“访达”。
2. 新建文件夹，命名为 `finance-agent-start`。Windows 可按 Ctrl+Shift+N，Mac 可按 Command+Shift+N。
3. 双击进入，确认里面是空的。先在本机可写的位置操作，不在邮件附件预览或压缩包内部工作。
4. 把文件扩展名显示出来。扩展名是文件名最后的 `.txt`、`.docx` 这一部分，后面会用它判断文件类型。

Windows 11 通常在资源管理器的“查看 → 显示 → 文件扩展名”。Windows 10 通常在“查看”选项卡勾选“文件扩展名”。Mac 在屏幕顶部“访达 → 设置 → 高级”中勾选“显示所有文件扩展名”。较旧版本可能写作“偏好设置”。

“路径”是文件在电脑上的位置，例如“文档里的 finance-agent-start 文件夹”。不同电脑的完整路径不同。后面让 AI 说出它实际打开的位置，不要照抄别人的用户名和路径。

### 你怎样确认完成

- 关掉这个文件夹窗口，再从“文档”中找到并打开它。
- 确认文件夹名字是 `finance-agent-start`，不是一个同名压缩包。
- 记住这个位置。稍后在 OpenCode 中选择的就是它。

### 没成功时

如果你在浏览器中看到了一个同名网页，还没有完成本步。回到文件资源管理器或 Finder，找到真实文件夹。出现“只读”或“无法创建”时，换到本人有写入权限的本机位置；单位电脑不允许安装或写入时，先处理这项限制。

## 第2步：分清软件、模型和两类 API

先用下面这张表把名字对上。你不需要记住英文缩写的全称。

| 名字 | 本课程里用来做什么 | 它不是哪一项的完成证明 |
| --- | --- | --- |
| OpenCode | 安装在电脑上的编程智能体工具。读项目、写文件、运行和修改程序 | 装好软件，不代表已连接模型 |
| DeepSeek | 本路线中给 OpenCode 提供思考和编程能力的在线模型服务 | 聊天网页能用，不代表 API 已有额度 |
| 硅基流动，SiliconFlow | 提供多种托管模型的调用服务。课堂做出的程序通过它读取财报、公告或图片 | OpenCode 能回复，不代表这些程序已配置好它的 Key |
| 同花顺金融数据服务 | 返回证券身份、财务报表等结构化数据，第二讲用它做外部核对 | 普通同花顺软件能登录，不代表这里的 API 已开通 |
| 巨潮资讯 | 第三讲查询上市公司公告和原始 PDF 的来源 | 浏览器能打开，不代表你做出的程序已经会查询 |

“硅基流动”是平台名称，不是“轨迹流动”。它上面有多种模型，Qwen 是其中的一个模型系列。模型名称和提供服务的平台名称，要分开看。

### API 就是让程序提出请求的入口

你在网页里选公司、点查询，是人在操作网站。程序通过 API 发送“查询哪家公司、哪个报告期”的请求，再接收结果。API 通常同时规定请求地址、填写哪些条件、需要什么授权、返回哪些内容。

本课用到两类 API。

- 模型 API。把文字或图片交给模型，要求它提取、判断或回答。返回的是模型生成的内容，仍可能读错或编造。
- 数据 API。向数据服务查询具体记录，例如某公司某期合并利润表。返回的是该数据源的记录，仍要核对公司、期间、单位和口径。

数据 API 的结果也不是天然正确的“标准答案”。模型提取值和数据服务值不一致时，要回到原文，检查是不是期间、合并口径、单位或后续更正不同。

### 把两条调用路线分开看

一个账号的 Key 一般不能拿去另一个平台使用。DeepSeek 和硅基流动即便都显示过“DeepSeek”模型名，服务地址、Key、额度和实际可用模型也分别由提供方管理。

### 这几个词接下来会反复出现

| 词 | 现在需要理解的意思 |
| --- | --- |
| 账号 | 你在某个平台的身份，用手机号或邮箱登录 |
| API Key，密钥 | 程序调用服务时使用的授权凭据，不是登录密码，也不是验证码 |
| 额度、余额 | 账号还能使用多少服务。创建了 Key，不代表一定能调用 |
| 模型 ID | 请求中填写的准确模型名字。不能把宣传名称随意当作 ID |
| Prompt，提示词 | 你发给 AI 的任务说明。普通中文也可以 |
| Agent，智能体 | 模型结合工具和运行程序，按任务读取资料、采取行动、检查并继续工作的系统 |
| 工具 | 读文件、计算、查数据、运行程序等具体能力。是否能用，取决于当前系统实际提供了什么 |
| 工作流，workflow | 程序安排的一组处理步骤。第一讲先搭这样的流程，逐步认识模型和工具怎样配合 |
| Token | 服务计算文字处理量时使用的单位。不是固定一个汉字，读入长文和生成回答都会占用量 |
| 上下文 | 模型本次能参考的任务、对话和工具返回。文件在电脑上存在，不代表内容已经进入上下文 |
| 环境变量 | 程序启动时可读取的一项设置，例如告诉程序去哪找授权。本人配置过后，还要检查新启动的程序能否读到 |

下文标为“发给 OpenCode”的文字是任务说明，里面的工具名和参数主要是给 Agent 看的。你现在不用背这些名称。先复制当前一条，等它做完，再按“你怎样确认完成”检查结果。标为“系统终端”的命令只放进终端，不发进聊天。

本课程使用在线托管模型。4B、27B 这样的字样描述模型参数规模，不要求老师把模型下载到电脑，也不要求购买显卡。

## 第3步：安装 OpenCode，并连接自己的编码模型

这一步会使用本人账号，模型调用可能计费。先查看提供方的计费和可用额度，按需要准备。这里不承诺固定赠送金额，也不要求购买某个订阅。

### 安装桌面版

1. 在浏览器打开 [OpenCode 官方下载页](https://opencode.ai/download)。
2. 找到 **OpenCode Desktop**。这是桌面版。不要复制页面上方 OpenCode Terminal 的安装命令。
3. Windows 通常选 Windows x64。如果系统“设置 → 系统 → 系统信息”注明 ARM，则选 ARM64。
4. Mac 在屏幕左上角“苹果菜单 → 关于本机”查看。“芯片”写 Apple M 系列的选 Apple Silicon，“处理器”写 Intel 的选 Intel。
5. 打开下载的安装文件，按系统安装步骤完成。Mac 的 `.dmg` 通常需要把 OpenCode 图标拖入“应用程序”，再从“应用程序”启动。Windows 按安装程序提示完成后，从开始菜单打开。

系统出现来源或权限提示时，先核对安装文件来自上面的官方网站。不要为了继续而关闭系统的安全保护。若单位限制安装，记录提示，联系本单位负责软件安装的人员。

### 在 DeepSeek 开放平台取得 Key

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，按页面要求注册并登录。已有账号直接登录。
2. 查看账户余额、充值或计费页面，确认 API 可以使用。日常聊天应用与开放平台调用的计费不能混为一项。
3. 在 **API keys / API 密钥** 中创建一把自己的 Key，起一个能认出的名称，例如 `finance-course`。
4. 按平台提示复制完整 Key。接下来只粘贴到 OpenCode 的提供商授权框，不粘贴到聊天输入框。

只看到了账号首页，还没有完成本段。需要确认自己已经取得 Key，而且账号具备可调用条件。已有可用 Key 的老师不必再建一把。

### 在 OpenCode 中连接 DeepSeek

下面的中文按钮已按 macOS 上的 OpenCode Desktop 1.19.4 核对。Windows 安装步骤按官方说明编写，尚未做 Windows 实机走查。不同版本的名称可能略有差异，先找同一功能，不要把终端教程中的命令硬套进桌面界面。

1. 点击 **主页**，再点击左下方的 **设置**。
2. 在设置中选择 **提供商**。找不到 DeepSeek 时，点击 **查看更多提供商**。
3. 在 **搜索提供商** 中输入 `DeepSeek`，选择 DeepSeek。
4. 在 **DeepSeek API 密钥** 输入框粘贴自己的 Key，点击 **继续**。已连接且能用的，不需要断开重连。
5. 返回主页，点击 **添加项目**，选中第1步的 `finance-agent-start` 文件夹并打开。
6. 在该项目中新建一个会话。点击会话输入框附近的模型名称，选择 **DeepSeek 提供商**下的 Flash 模型。若列表没有显示，先在“设置 → 模型”中搜索并启用它，再回会话中选择。

本次核对看到的名称为 `DeepSeek V4.1 Flash 1017`，官方 API 当前名称为 `deepseek-flash`。课堂第二讲的参考编码配置是 `deepseek/deepseek-flash`，High 推理档。若界面提供推理强度选项，先选 High。显示名称可能更新，以官方说明和你实际选择的模型 ID 为准。不要仅凭模型在回答中自称的名字判断。

已在使用其他合适的编程工具或模型的老师可以沿用。上面的 DeepSeek 注册仅供选择这条路线的人使用。

### 发出第一句话

在 OpenCode 的大输入框中发送下面这句话。Windows 用 Ctrl+V 粘贴，Mac 用 Command+V。点击发送，等回复结束。

```prompt
请只回复“连接成功”。先不要读写文件，不运行命令。
```

### 你怎样确认完成

- 当前项目名是 `finance-agent-start`，会话旁显示你实际选择的模型。
- 收到正常回复，没有认证、余额、网络或模型不存在的错误。
- 本段只证明编码模型能回复。读写文件要到第5步再检查。

### 没成功时

先看原始错误。401 或“密钥无效”通常先核对提供商和 Key；余额或配额错误去对应平台查看；模型不存在则核对模型 ID。网页能聊天而 OpenCode 报错时，回到开放平台检查 API 授权，不要反复新建项目。

若界面不同而找不到连接入口，对照 [OpenCode 提供商说明](https://opencode.ai/docs/providers/) 和 [DeepSeek 的 OpenCode 接入说明](https://api-docs.deepseek.com/quick_start/agent_integrations/opencode/)。后者包含终端版操作，桌面版优先用上面的点击路线。

发送任务以后，每次等当前回复结束，再核对结果、发送下一条。后面几步都在同一项目和会话中继续。第6步选文档时，先只做一份，确认后再换下一份。

## 第4步：确认电脑能运行课堂程序

OpenCode 能回复，说明它接到了在线模型。课堂做出的网页、PDF 读取和数据查询，还需要本机的运行环境。

Node.js 和 Python 是运行程序所需的软件。你现在不需要学它们的语法。Node.js 会用在第一讲和同花顺命令工具中，Python 及 PDF 读取、渲染工具会用在后续讲次。先检查已有环境，缺什么再补。

### 把这条发给同一个会话

```prompt
我没有编程经验，正在做金融智能体课前准备。只检查当前电脑和 finance-agent-start 项目的运行条件。

请实际检查操作系统、项目完整路径、项目能否读写、Node.js 和 npm、Python 3。Node.js 要满足同花顺 CLI 的最低要求 22.12.0。不要仅凭目录存在判断已安装。不要读取或显示任何 API Key，不调用收费服务。

把结果写成 preflight-environment.md，每项只写“已实际检查”或“缺失”，附实际版本和检查方法。没有执行条件的写“待检查”。先不搭建课堂应用。

缺少 Node.js 时，给我适合当前系统的官方网站图形安装步骤。缺少 Python 时，说明采用系统 Python、项目环境还是官方安装程序，给出一个明确的下一步。不要同时让我安装多套工具，也不要更改其他项目。
```

OpenCode 弹出运行或写文件的权限请求时，看清它要做什么。读取本项目、在本项目保存检查文件、执行本步说明的检查，都与当前任务相符。不理解的请求先让它解释。不要开启“自动接受所有权限”来省略判断。

### 缺 Node.js 时怎样安装

1. 打开 [Node.js 官方下载页](https://nodejs.org/en/download)。选择标为 **LTS** 的版本，并确认不低于 22.12.0。
2. 找页面上的预编译安装程序。Windows 选择适合系统的 **Windows Installer / `.msi`**，Mac 选择 **macOS Installer / `.pkg`**。此处不用复制页面上方的 nvm、Docker 或其他终端安装脚本。
3. 打开安装文件，按提示完成。已有满足条件的 Node.js 就跳过，不重复安装。
4. 完全退出并重新打开 OpenCode，再进入同一个项目和会话。仅关掉会话标签页不一定会重新读取安装后的环境。
5. 发送“安装已完成，请重新实际检查 Node.js、npm 和 Python，并更新 preflight-environment.md”。

如果还缺 Python，按 Agent 针对当前系统给出的步骤补齐，官方入口是 [Python 下载页](https://www.python.org/downloads/)。PDF 专用依赖让各讲第0步在对应项目内安装，不要求老师手工追着安装一串软件包。

### 先认识“终端”，但不用先学命令

终端是电脑上接收程序指令的窗口。OpenCode 的对话框是给 AI 说任务的地方，终端是让电脑执行命令的地方，浏览器地址栏是打开网址的地方。三处不能混贴。

以后需要本人输入密钥时，可能会用到终端。Mac 按 Command+空格，搜索“终端”或 `Terminal`。Windows 打开开始菜单，搜索 `PowerShell` 并打开普通用户窗口。命令的具体内容由当前步骤给出；不在终端里发送给 AI 的中文需求，也不把密钥写进命令行。

### 你怎样确认完成

- 在电脑文件夹中找到并打开 `preflight-environment.md`。如果双击不能预览，可右键选择记事本或文本编辑打开。
- 它写的是你电脑的实际版本和路径，Node.js 满足条件，Python 可以执行。
- 安装后重新检查过。写着“建议安装”“计划检查”不算通过。

### 没成功时

```prompt
请只解决环境检查中第一个仍未通过的项目。告诉我当前失败信息、我需要在哪个窗口做什么、做完应看到什么。完成后实际复查并更新记录。不要把“已给出安装建议”写成“已安装”。
```

## 第5步：让 AI 读到只有文件里才有的内容

这一步用来分清“AI 在聊天里说知道了”和“AI 确实读了电脑文件”。你要亲手写入一个它事先不知道的核对词。

### 先自己创建一份纯文本

Windows 在 `finance-agent-start` 文件夹的空白处右键，选择“新建 → 文本文档”，命名为 `my-check.txt`，用记事本打开。如果系统没有这个菜单，先打开记事本，再“另存为”到这个文件夹，保存类型选“所有文件”，编码选 UTF-8。

Mac 打开“文本编辑”应用，新建文稿。先选“格式 → 制作纯文本”，再输入内容。保存到 `finance-agent-start`，命名为 `my-check.txt`。若保存对话框有纯文本编码选项，选 UTF-8。不要保存成 RTF。

写入下面三行，把第三行换成**你自己选择的四个汉字加四位数字**。不要把换好的第三行发进聊天。

```text
这是我的金融智能体课前准备记录。
我使用的是自己准备带来上课的电脑。
核对词：在这里写我自己选择的内容
```

保存后关掉文件，再打开一次，确认内容还在。文件名应为 `my-check.txt`，不是 `my-check.txt.txt`、`my-check.txt.rtf` 或 `my-check.txt.docx`。

### 让 OpenCode 实际读取

```prompt
请实际读取当前项目的 my-check.txt。告诉我文件的完整路径，并逐字引用第三行。不要让我把文件内容复制进聊天，读不到就明确说读不到。

然后在同一项目新建 agent-readback.md，保存你读到的三行原文，并写明来源文件名。不改动 my-check.txt。
```

### 你怎样确认完成

1. 比较 AI 引用的核对词，确认与自己亲手写入的四个汉字和四位数字完全一致。
2. 在电脑文件夹里找到新增的 `agent-readback.md`，打开检查三行原文。
3. 再打开 `my-check.txt`，确认原文件还在、内容未改。

核对词一致，加上新文件实际存在，才通过。AI 只在回复里排出一段 Markdown，而电脑上没有新文件，不通过。它要求你把全文贴进聊天，也还没有证明读取成功。

### 认识一下 Markdown

`.md` 是 Markdown 文件。它的内容仍然是文字，用一些可见符号表示结构。例如 `# 标题` 表示一级标题，`- 内容` 表示列表。你不必先装一个 Markdown 编辑器，OpenCode 可以创建和修改，记事本或文本编辑也能查看原文。

让 AI 把上述记录加一个标题和一段列表。你会看到 `.md` 文件里仍能直接读到文字，只多了标题和列表的符号。把 Word 改名为 `.md` 不会完成转换。

### 没成功时

```prompt
读取还未通过。请实际列出当前项目里的文件名，检查是否选错目录、文件尚未保存、扩展名重复或保存成了 RTF。只修复读取方法，保留原文件。重新读取成功后再创建 agent-readback.md，并让我去电脑文件夹核对。
```

## 第6步：亲自检查 Word、PPT、PDF 是否读对

文件能打开、工具能读出一些字、模型理解了原文，是三件不同的事。Word、PPT、PDF 都能借助合适工具读取，但结构、图像和版面可能在中间丢失。判断依据是读取结果与原文件能否对上。

### 先按内容选格式

| 文件 | 适合保存什么 | 交给 Agent 时重点检查什么 |
| --- | --- | --- |
| `.txt` 纯文本 | 连续文字、简单记录 | 没有丰富版式，标题和表格关系要写清楚 |
| `.md` Markdown | 任务说明、带标题的笔记、步骤和报告正文 | 文字结构直接可见，图片和复杂表格仍需另读 |
| `.html` 网页 | 可在浏览器阅读的报告、带样式的页面 | 浏览器显示与源文件不同。动态网页还可能需要实际打开页面才能取到内容 |
| `.docx` Word | 正式文稿、审阅和排版 | 正文可能读到了，文本框、页眉、批注、图片或合并单元格未必读全 |
| `.pptx` PPT | 投影展示、图表、图形关系 | 文字读取顺序未必等于观看顺序，箭头、图表、图片和备注可能遗漏 |
| `.pdf` PDF | 固定页面的正式材料和原始证据 | 先判断有无可用文字层，再核对顺序、表格、页码和图片 |
| `.csv` 表格文本 | 一行一条的简单数据，便于程序读取 | 单位、日期、缺失值、编号和编码要明确，不保存公式、批注或多个工作表 |
| `.json` 结构化记录 | 程序交换字段明确的数据 | 字段名、数字、文字、空值有明确区别，需要按约定格式保存 |
| `.xlsx` Excel | 多工作表、公式和复杂表格 | 公式与计算结果、隐藏行列、合并单元格和单位需要分别检查 |

对任务说明和连续文字，Markdown、纯文本往往省去了一层格式解析。HTML 也能清楚呈现内容和结构。它们都不能自动保证正确；把混乱表格转成 Markdown，表格仍可能混乱。

保留 Word、PPT、PDF 原件。需要给 Agent 更容易处理的文字时，另存一份转换结果，注明来源。原件用于回看和核对。旧版 `.doc`、`.ppt` 可先用 Office 另存为新版格式副本，不靠修改扩展名转换。

### 自己做一次 Office 读取检查

从自己已有资料中选一份非敏感 Word 或 PPT。挑一段正文，再挑一个容易漏读的内容，例如 Word 文本框、PPT 箭头两端的文字、图表标题、演讲者备注。把文档的一个副本放进工作文件夹。没有相应内容时，不必为了本步去制作复杂文档。

```prompt
请先列出当前项目中的 Word 和 PPT 文件，让我选一份。选定后，实际检查能用什么方法读取它，说明这次读到了哪些部分。

先给出文件中一段正文的原文，再检查文本框、图表、图片、箭头关系或备注是否能读取。需要看页面或幻灯片图片时，说明并实际读取；无法读取的明确列出。不要因为提取到正文，就宣布整份文档已经完整理解。

保留原文件，把读取方法、能读与未读的部分记入 document-check.md。等我核对后再继续。
```

打开原文件逐字对照那段正文，再检查你事先选定的特殊内容。需要时在同一会话指出“第几页或第几张幻灯片，哪一处没有读对”。如果需要补一种读取工具，先让 Agent 说明安装什么、为什么需要，再按本机情况处理。

### PDF 要单独做这个判断

用浏览器或 PDF 阅读器打开自己的一份非敏感 PDF。可用一份公开公告，也可以在 Word 中把一页自己的非敏感文字另存为 PDF。Word 通常在“文件 → 另存为”选择 PDF，或在“文件 → 导出”创建 PDF，保留原来的 Word 文件。后者只是用来检查读取方法，不是财务运行。

1. 用鼠标拖选一句正文，再复制到记事本或纯文本编辑器。
2. 看复制出来的文字是否与页面相同。能选中且文字正确，说明至少这一区域有可用文字层。
3. 如果只能选中整张页面图片、选不到字，通常需要 OCR，也就是文字识别，或能看图片的视觉模型。
4. 再挑一行有表头的表格，复制出来核对。能选字也可能出现多栏混排、列错位或乱码。

有些扫描 PDF 已经做过 OCR，所以也能选字。不能仅凭能选中文字就断定它原本是文字排版 PDF。你要判断的是这次能否可靠读取。

把 PDF 副本放到工作文件夹后，发送：

```prompt
请实际检查我选定的 PDF。先判断文字层是否可用，选一页保存提取结果，告诉我采用的是文字提取、OCR 还是页面图像读取。

引用这一页的一句原文。如有表格，再引用一个表头和对应的一行数字，保留年份、单位、负号和空白。不要计算，也不要补出原文没有的内容。告诉我 PDF 物理页号；若页面印刷页码不同，也分别写出。

把结果补进 document-check.md，等我打开原 PDF 核对。若当前工具或模型不能看图，直接写明限制和需要补的能力，不能把空白提取结果当成“原文没有内容”。
```

### 你怎样确认完成

- Office 正文与原件对得上，特殊内容是否读到有明确记录。
- PDF 的一句原文对得上。有表格时，表头、该行数值、单位和负号也对得上。
- 你能说出当前 PDF 用了哪种读取方法，以及哪些地方仍未读到。
- 如果手边只有一种 PDF，只记录实际检查过的这一种。扫描 PDF 的读取能力未测试，就写“待测试”，不勾成两种都通过。

第一讲直接提供完整财报文本，第二讲要从 PDF 文字和原始页图独立核对，第三讲要读取公告 PDF。后两讲的 PDF 工具由对应项目的第0步继续检查。课前这一步先学会识别问题和回看原文。

### CSV 和 JSON 只要先看懂一个区别

下面是说明格式的虚构记录，不是上市公司数据，也不需要下载。

```csv
资料编号,报告期,收入_万元,备注
0007,2026H1,123.40,教学示例
```

CSV 第一行是列名，下一行是一条记录。编号 `0007` 是文字标识，不能因为 Excel 自动处理而变成 `7`。CSV 不保存 Excel 的公式或单元格颜色。中文乱码时先核对 UTF-8 等编码；编号和日期被自动改写时，要用 Excel 的文本或 CSV 导入入口指定类型，不能保存覆盖原件。

同一条记录也可以写成 JSON：

```json
{
  "record_id": "0007",
  "period": "2026H1",
  "revenue": 123.40,
  "unit": "万元",
  "source_page": null,
  "note": "教学示例"
}
```

这里的 `record_id` 是字段名，`"0007"` 是文字，`123.40` 是数值，`null` 表示此处没有填写页码，不能当成第0页。JSON 数值重新显示为 `123.4` 不改变金额含义；若要保留原文的小数位，另存原始文字。中文说明不会因为换成 JSON 就变成可信数据。

### 没成功时

```prompt
请只处理我指出的这一处读取错误。先说明错误来自文字提取、OCR、图像理解还是表格对应关系，再实际换一种合适方法读取。保留原文件和前一次结果，给我一小段可以回原件核对的新结果。无法处理时写明限制，不要猜答案。
```

## 第7步：准备硅基流动，让自己的程序实际调用模型

这项 Key 用于你做出的财报、公告程序。它与 OpenCode 的编码模型授权分开配置。下面先做一次小范围连接检查，不读财报、不运行整份分析。

### 在控制台完成本人账号操作

1. 打开 [硅基流动控制台](https://cloud.siliconflow.cn/)，注册或登录。
2. 按账号当前要求完成认证，查看可用额度、代金券使用条件及模型价格。是否有赠送、能用在哪些模型、何时到期，以本人控制台为准。
3. 在 **API 密钥 / API Keys** 页面新建自己的 Key，已有可用 Key 就沿用。
4. 在模型列表中查看课程所需模型是否可用。第一讲当前使用 `Qwen/Qwen3.5-4B`；第二讲默认使用 Qwen 27B 并需要文字与视觉能力；第三讲从 4B 起步，再作比较。不要在课前下载这些模型。

准确的模型 ID 会随各讲材料和服务目录更新。第二、三讲当前材料中包含 `Qwen/Qwen3.8-27B`。连接检查先核对账号实际可用列表，不把“没有报错”当成所需模型一定存在。

### 给第二、三讲准备用户级凭据

“用户级”是指保存在你自己的电脑账户下，供程序按约定查找，不放进某个课堂项目，不随项目分享出去。

两讲当前约定是：先读取 `SILICONFLOW_API_KEY` 环境变量；没有时，Mac 使用 `~/.config/siliconflow/credentials.env`，Windows 使用 `%APPDATA%\siliconflow\credentials.env`。这些是让 Agent 找准位置的说明，不要求老师手工猜路径。波浪线表示本人用户目录，`%APPDATA%` 是 Windows 的本人应用配置位置。

把下面这条发给 OpenCode。它应先检查状态，缺失时才指导你本人输入。

```prompt
我需要配置课堂程序使用的硅基流动凭据。请先按下面顺序检查是否已有配置，只报告“已存在”或“缺失”，不显示密钥，也不读取 OpenCode 的私有登录文件。

优先读取 SILICONFLOW_API_KEY；否则 Mac 读取 ~/.config/siliconflow/credentials.env，Windows 读取 %APPDATA%/siliconflow/credentials.env。

缺失时，请给出适合当前操作系统的一条明确配置路线。需要我在系统终端输入时，给出完整命令并告诉我怎样打开那个终端。实际 Key 必须在隐藏输入提示出现后由我本人粘贴，不写进命令、聊天或项目。配置文件只允许本人读取和写入。

配置完成后，让新启动的检查程序按同一路线确认可以读到配置，只报告状态。先不要发模型请求。不要让我把 Key 发到聊天。
```

### 本人输入时怎么操作

1. 看清 Agent 给出的步骤属于 Mac 终端还是 Windows PowerShell，打开对应窗口。
2. 复制它给出的配置命令，执行。命令里应没有你的真实 Key。
3. 只有出现明确的密钥输入提示后，才粘贴 Key 并按回车。隐藏输入时看不到字符或星号可能正常，不需要把它显示出来确认。
4. 回 OpenCode 告诉它“本人输入已完成，请只检查配置状态”。

如果 Agent 要你把 Key 发进聊天，先不要发，改用这一句：“请改成我本人在本机隐藏输入的方式，不让真实密钥出现在聊天、命令参数或项目文件中。”

### 再做一次真正的连接检查

这一步会向硅基流动发出真实请求，可能产生少量费用。自己核对价格和额度后，再发送下面这条。不要用控制台在线体验成功替代程序调用成功。

```prompt
请使用刚配置的本人硅基流动凭据做最小真实连接检查。先核对当前官方模型列表，确认 Qwen/Qwen3.5-4B 是否可用。模型不存在时停下，说明原因，不静默换模型。

若可用，只发送一次很短的文字请求，要求回复“连接检查通过”。使用与该模型匹配的短输出限制，不读财报，不自动循环重试。

将检查时间、服务方、请求模型 ID、服务实际返回的模型字段、是否成功、返回的短文本、用量是否可知写入 siliconflow-check.md。没有返回的字段写“未提供”，不编造。记录中不含请求头或密钥。失败就保留真实错误并停下。
```

### 你怎样确认完成

- 电脑中有 `siliconflow-check.md`，记录了一次真实请求和实际回复。
- 记录明确写硅基流动与请求模型，不能拿第3步 OpenCode 的回复充数。
- 控制台用量如能查到，可作辅助核对；更新可能有延迟，不能只凭余额没变判断失败。
- 此时只证明该文字模型可调用。第二讲的视觉读取还需在该讲检查，不能提前写成视觉也已通过。

第一讲另有一项操作：在自己做出的本机网页里，把同一平台的个人 Key 粘贴到 Evals 的隐藏输入框，供本次运行使用。第7步的用户级配置不会自动替网页填写它。到第一讲按讲义操作，不要现在把 Key 写进 HTML。

### 没成功时

```prompt
请先说明这次失败是在读取本机配置、认证、额度、模型 ID、请求参数还是网络阶段。只给一个明确的下一步，不反复调用，也不更换提供商。缺失与已存在但无效要分开。没有真实成功前，将 siliconflow-check.md 保持为未通过。
```

## 第8步：准备同花顺数据服务，并打开巨潮原公告

两项来源的用途不同。同花顺用于取结构化财务数据，巨潮用于回看公告原文。本步分别检查。

### 取得同花顺金融数据 API Key

1. 打开 [同花顺金融数据服务的 API Key 管理页](https://fuyao.aicubes.cn/admin/)。这是本课程使用的服务入口。
2. 未登录时先点 **登录** 或 **去登录**，按页面要求完成本人注册和登录。

4. 确认本人账号当前的数据权限、限额和费用规则。安装普通行情软件不能替代这一步。

### 先让 OpenCode 检查工具

本课用 `hithink-finance` 命令工具接入。你可以把它理解为供程序使用的查询工具。CLI 指这种命令入口，不是另一份金融数据库。



等待工具出现密钥输入提示，再粘贴本人同花顺 Key，按回车。然后回 OpenCode 请它实际检查认证状态。若当前终端不支持隐藏输入，让 Agent 改用适合本机的方式，不把 Key 放入聊天或命令参数。

已存在统一凭据时，让 Agent 复用并同步给 CLI，不需要再输入。若这里只完成了 CLI 的本机登录，就如实记为“CLI 认证”，其他网页和软件的授权仍要分别确认。

### 查询一次，核对到真实数据

数据请求可能占用服务额度。确认本人权限后发送：

```prompt
请用本人已配置的同花顺服务做一次有界的真实查询。先确认“伊利股份，600887”的证券身份，再查询这家公司 2026 年半年报的合并利润表。使用当前工具的 financials.income 能力和实际 schema，不猜参数，不下载全市场。
```

### 再打开巨潮原公告

1. 在浏览器打开 [巨潮资讯](https://www.cninfo.com.cn/)。
2. 搜索 `600887`，确认公司为伊利股份，再找一份业绩说明会通知或相关公告。第三讲还会使用嘉和美康 `688246`。

4. 看 PDF 的公司名称、标题和日期，确认它与列表中选择的公告相符。只看到搜索摘要还没有通过。

第三讲当前流程从巨潮公开网站查询并下载公告，不要求课前另外购买“巨潮 API Key”。如果网站要求本人验证，按网站提示完成；遇到网络或访问限制，记录实际情况。

## 第9步：让 AI 生成网页，并学会重新打开它

本步只展示你自己的课前记录，不提前搭建前三讲的课堂应用。它让你确认 AI 的结果能保存、能打开、能修改，而不是只停在对话里。

### 先做一个可直接打开的 HTML

```prompt
请根据 my-check.txt 和 agent-readback.md，在当前项目创建一个独立的 my-start-page.html。只用本地文字，展示标题、我写的三行原文、来源文件名和“这是课前准备记录”。不调用外部服务，不放密钥，不编造其他检查已通过。

网页无需联网也能显示。完成后告诉我文件的完整位置，让我先在电脑文件夹里双击打开核对。不要只把 HTML 代码贴在聊天里。
```

在文件夹里双击 `my-start-page.html`，浏览器中应该看到排好版的文字，而不是一整页 `<html>` 代码。地址通常以 `file://` 开头，表示打开本机文件。如果系统用文本编辑器打开它，可右键选择“打开方式”，改用浏览器。

回到 OpenCode，要求“只把网页标题改成‘我的课前准备已开始’，保留三行原文”。等它实际保存，再在浏览器刷新。检查标题变了，原文还在。

### 再认一次本机网址

后面的课堂程序还会有后台服务。后台程序运行着，浏览器才能通过本机网址访问它。你可以先用刚才的静态页面确认一次启动与停止：

```prompt
请只为当前项目启动一个本机静态预览服务，展示 my-start-page.html。只监听 127.0.0.1，选用空闲端口，不开启公网访问，不停止其他项目。实际确认页面可访问后给我完整可点击网址，不只给示例。

请把实际启动和停止方法写入 RUN.md。开头先写我以后可以发给你的两句中文请求：“按 RUN.md 启动本项目并给出实际网址”和“只停止本项目的预览服务并确认”。不要自动打开收费调用或创建定时任务。
```

打开它实际给出的 `http://127.0.0.1:端口/...` 网址。`127.0.0.1` 或 `localhost` 指本机，端口用来区分本机运行的服务。数字以 Agent 实际启动的为准，不照抄讲义中的例子。

### 你怎样确认完成

1. 本机文件打开的页面里，有自己的核对词，标题修改也能看见。
2. 本机服务的网址确实能打开同一页面。能否打开以你在浏览器看到为准。
3. 发“请按 RUN.md 只停止本项目预览服务并确认”。停止后，在网址后附上 `?check=stop` 重新访问，或者强制刷新，确认出现连接失败。原先已打开的页面可能仍留着画面，不能把旧画面当成仍在运行。
4. 再发“请按 RUN.md 启动本项目，确认可访问后给我实际网址”。重新打开它给出的地址，页面恢复。

只要你做出了上述可见结果，就已经理解了后续课堂里“启动、打开、修改、重启”的基本操作。

把这个本机网址发给另一位老师，对方访问的是对方自己的电脑，不会看到你的程序。换电脑要带走整个项目文件夹，并重新检查环境、授权和启动方法。

第三讲的定时任务也是运行在某台实际电脑或服务器上。仅仅在聊天里说“每天检查”，不会自动获得持续运行能力。运行位置、开机与休眠、时区、触发记录和暂停方式，会在第三讲实际搭建并验证。

### 没成功时

```prompt
我在浏览器中没有看到预期页面。请实际检查网址、文件位置、本项目进程和端口，说明我现在打开的是 file 文件还是本机服务。只处理当前项目，给我一个已检查可访问的完整地址。后台改动需要重启时请实际重启，不能只让我重复刷新。
```

## 卡住时，先看是哪一层出了问题

| 你看到的情况 | 先检查什么 | 下一步怎么做 |
| --- | --- | --- |
| 模型一直在输出、按钮还是“停止” | 当前任务是否仍在运行 | 等本条结束再发下一步。长时间无进展时停止并保留记录，缩小到当前一项 |
| 只给方案，没有文件 | 是否允许编辑和执行，是否还在 Plan 规划模式 | 切到允许执行的模式。OpenCode 称 Build。要求实际写入，并亲自找文件 |
| 无法保存、EACCES、Permission denied | 本项目路径和写入权限 | 换到本人可写位置，重新选项目，不猜全局权限命令 |
| 明明装了软件，Agent 仍找不到 | 新进程是否读取了安装后的环境 | 完全退出再打开工具，实际复查版本 |
| 文件内容是乱码 | 读取方式和编码 | 保留原件，按实际编码读取，先核对一小段 |
| PDF 没有提取出字 | 有无可用文字层，是否需要 OCR 或视觉 | 检查页面图像和实际工具能力，不把空结果解释成空白文档 |
| API 返回 HTTP 200，却没有数据 | 业务状态、参数与权限 | 检查业务成功标志和原始响应。空数据不等于成功，也不自动等于服务故障 |
| 模型有回复，但数字不对 | 来源、年份、列头、单位、负号 | 回原文逐项核对。连接成功不等于业务正确 |
| 429 或限流提示 | 请求是否太密、并发是否过高 | 停止连续重试，按平台提示等待后小范围再试 |
| 网页打不开或改动没出现 | 服务是否启动，是否打开了旧网址 | 让 Agent 检查本项目实际进程并按需重启，再打开确认过的地址 |

可以把下面这段作为通用求助模板。补上当前步骤和脱敏错误，发在当前项目的同一会话中：

```prompt
我卡在第__步。讲义要求看到的是__，我实际看到的是__。错误信息是__，已经尝试过__。

请只解决这一项，先实际检查，再给我一个适合零基础用户的下一步。说明在哪个窗口操作、完成后应该看到什么、怎样确认成功。不要跳过本步，不编造通过结果，不让我提供密钥。
```
